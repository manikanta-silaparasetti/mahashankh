DPI / Resolution Conversion
Resamples the image to 72, 150, 300, or 600 DPI. Embeds DPI metadata in the output file so RIP software and print machines read it correctly. 300 DPI is the commercial print standard.
PIL · DPI metadata · LZW TIFF
Output Format Conversion
Exports to TIFF (lossless print standard), PNG (transparent alpha), BMP (raw uncompressed for RIP/vinyl), or JPEG (compressed digital). Format cards replace confusing dropdowns.
PIL · TIFF-LZW · PNG-Deflate
RGB → CMYK Color Conversion
Converts screen RGB images to 4-channel CMYK using High-Fidelity GCR (Grey Component Replacement) — replaces neutral grey mixtures with pure K (black) ink, saving ink and improving shadow depth.
NumPy · Custom GCR · PIL CMYK
Industrial Bleed Margin
Extends the artwork past the trim cut line by mirroring edge pixels outward. Default 3mm (industry standard). Supports mirror, clamp (stretch), and white matte fill modes. Live canvas overlay shows trim/safe zone.
NumPy · PIL · cv2.copyMakeBorder
Corner Crop & Registration Marks
Draws L-shaped hairline crop marks at all 4 corners and circular crosshair registration targets at edge midpoints. Used by press operators to align cutting blades and 4-color press plates.
PIL ImageDraw · Hairline rendering
AI Super-Resolution (Real-ESRGAN)
Multiplies pixel dimensions 2×, 4×, or 8× using Real-ESRGAN deep learning inference. Runs entirely on CPU via ONNX Runtime — no GPU needed. Processes in 512×512 tiles with overlap to prevent seams. Restores realistic textures.
Real-ESRGAN · ONNX Runtime · 67MB model
AI Background Removal
Detects and removes image background using AI segmentation, isolating the main subject with a transparent alpha channel. Output as PNG or TIFF with alpha for product photos, motif isolation and compositing.
rembg / OpenCV · Alpha channel
Rename Before Save
After conversion, an editable filename input appears above the download button. User types a custom name — the extension badge auto-syncs with the selected format (.tif / .png / .bmp / .jpg). Illegal characters are sanitised automatically.
Vanilla JS · Blob URL · File API
Live Bleed Preview: Before converting, a canvas overlay draws a red dashed trim line and green safe zone directly on top of the uploaded image — so the user sees exactly where the blade will cut before processing.

Cyan Channel Plate
Extracts the C channel from the CMYK image. Controls blue/teal ink density in the final print. Film-positive: areas of high cyan ink appear as dense black on a white film positive for screen exposure.
PIL .split() · NumPy invert
Magenta Channel Plate
Extracts the M channel. Controls red/pink/purple ink density. Critical for skin tones, flowers, and warm artwork in saree and garment printing. Separate plate means the operator can adjust magenta ink independently on press.
PIL · NumPy · Grayscale L mode
Yellow Channel Plate
Extracts the Y channel. Controls warm tone, gold, and bright colour density. In textile printing, yellow is the hardest to balance — a separate plate allows precise density control during print registration.
PIL · NumPy · Grayscale
Black (K) Channel Plate
Extracts the K (Key/Black) channel, which carries shadow depth, text sharpness, and dark detail. In GCR mode, neutral grey tones are converted to pure K — reducing ink usage and preventing muddiness in shadow areas.
PIL · GCR algorithm · NumPy
Registration Crosshairs
Draws precision circular crosshair targets (bullseye) at all 4 corners of every plate, outside the artwork boundary. Printers overlay all 4 plates on a light table to check alignment — crosshairs must line up perfectly for colour registration.
PIL ImageDraw · Circle + Hairline
Job Title Slug
Stamps the job name, channel name, and DPI in the white border area of each plate. Example: "MahaShankh Plate • CYAN CHANNEL • Kanchipuram-SS2024 • 300 DPI". Operators can identify plates on the floor without confusion.
PIL ImageDraw.text()
ZIP Bundle Export
All 4 plate TIFFs plus the original RGB preview are packaged into a single in-memory ZIP archive — named after the job title and DPI. Single download delivers everything the print studio needs for one job.
Python zipfile · in-memory BytesIO
Ink Coverage Report
After plate generation, the backend returns per-channel ink coverage percentages (e.g. "Cyan: 42.3%"). Displayed as colour-coded bar graphs in the UI. Helps operators estimate ink consumption and cost before printing.
NumPy mean() · JSON response
Plate DPI: Select 300 DPI for standard textile screen printing, or 600 DPI for fine-detail screens, premium packaging, and photographic halftone reproduction.

Feature 03 — Saree & Textile Pattern Repeat Engine
Seamless Edge-Matched Fabric Tiling
Takes any motif or block and generates a seamless, edge-matched tile repeat across a configurable grid — ready for saree, textile, and fabric printing production. Supports three professional repeat modes used across the Indian weaving industry.
Half-Drop Repeat (50% Brick)
The most common saree and textile repeat mode. Alternating columns are offset by 50% vertically — preventing the eye from tracking horizontal repetition lines. Creates a natural, flowing rhythm across the fabric width. Used by 80%+ of Kanchipuram and Banarasi weaving units.
NumPy tile · vertical offset
Straight Grid Repeat
Tiles the motif in a perfect aligned grid — rows and columns lock up precisely. Best for geometric patterns, chevrons, checks, and abstract prints where symmetry and alignment are intentional design choices.
NumPy tile · PIL paste
Mirror Reflection Repeat
Alternates between the original and its horizontally/vertically flipped versions. Creates bilateral symmetry across tile boundaries — ideal for border prints, paisleys, and mandala motifs where the design needs mirror symmetry at tile edges.
PIL transpose · FLIP_LEFT_RIGHT
Edge-Matched Seamless Tiling
The output image tiles without any visible seam or cut line — edges are mathematically matched so that when the pattern is printed across the full fabric width, repeats are invisible to the eye. Essential for quality textile production.
PIL paste · offset stitching
Configurable Grid Size
Sliders for columns (2–6) and rows (2–6) control how many tiles appear in the output grid. A 3×3 grid generates a 9-tile composite preview of how the motif will look across the fabric surface — helping designers verify scale and density before printing.
NumPy hstack + vstack
High-Res PNG Export
Outputs the full tiled pattern as a high-resolution PNG preserving the original motif quality. The exported file can be directly fed into a textile CAD system, printed on sample yardage, or used as a reference for the weaving programme.
PIL PNG · FastAPI streaming
Industry Use: Half-Drop is the standard for Kanchipuram silk saree pallus. Straight Grid is used for Ikat and block print designs. Mirror Reflection is popular for border work and symmetrical buta motifs.

Brightness Threshold Binarisation
Converts the image to greyscale, then applies a configurable threshold (0–255). Pixels darker than the threshold become solid ink paths; lighter pixels become transparent background. Adjustable via slider — 127 default for clean black/white line art.
cv2.threshold · THRESH_BINARY_INV
OpenCV Contour Detection
Runs OpenCV's findContours algorithm on the binary mask to detect all closed outline paths in the image — from the outermost silhouette down to internal detail holes. Hierarchical retrieval preserves the nesting of internal contours (e.g. letters with counters).
cv2.findContours · RETR_TREE
Path Simplification (Douglas-Peucker)
Reduces the number of points on each contour using the Douglas-Peucker algorithm. The epsilon slider (0.5–8.0) controls how aggressively corners are simplified — low epsilon keeps fine detail, high epsilon produces smooth simplified curves for CNC cutting.
cv2.approxPolyDP · Douglas-Peucker
SVG Export
Generates a standards-compliant SVG file with all detected contours as <path> elements. SVG scales to any size without quality loss — opens directly in CorelDRAW, Inkscape, Adobe Illustrator, and all web browsers.
SVG path d= · Python string template
DXF Export (CNC / Embroidery)
Generates a DXF (Drawing Exchange Format) file with all paths as LWPOLYLINE entities — the universal format for CNC laser cutters, vinyl plotters, Tajima/Barudan industrial embroidery machines, and CAM software.
ezdxf · LWPOLYLINE entities
Both SVG + DXF ZIP Bundle
Optionally exports both SVG and DXF together in a single ZIP archive — giving the studio both the web-compatible vector and the machine-compatible cutting file in one download. Saves time when delivering to clients who use different software.
Python zipfile · BytesIO in-memory
CNC Tip: Use threshold 80–100 for laser cutting paths — this ensures only fully solid areas generate cutting paths, avoiding stray half-tone paths that waste machine time and cause burn-through on thin materials.
